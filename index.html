The stack, end to end

Most hardware careers specialise into one band and stay there. Mine has not. The same hands characterised a PIN-diode metasurface on a vector network analyser and wrote compiler passes that target a reconfigurable array — and in between, the boards, the flight software and the transport stacks that connect the two.

The range is the point rather than a coincidence. Accelerators fail at the seams: the clock-domain crossing, the memory traffic nobody budgeted for, the reliability number that arrives after the design is frozen. Those seams are only visible from both sides.
